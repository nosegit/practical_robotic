-----------------------------------
|Robot Software/firmware Structure|
-----------------------------------
Arduino - just upload PRBot.ino
        - everything had written in OOP base.
            - Sensor
            - Odometry
            - Motor
            - Communication
            - RobotState

Raspberry pi - Consist of 3 main Node : 
            - Driver/robot_service.py
                -   This node is Publish/Subscribes and Request/Reply for communication with Low-level (Arduino)
                -   Publish/subscribes service for streaming Low-level state at PORT: 5555
                -   Request/Reply service for Client to command Robot (Low-level) velocity (lineat, angular) at PORT: 5556
            - Vision/camera_server_vid.py
                -   This node is Publisher that publish Detection data and JPEG video streaming from PIcamera
                -   1st Publisher : publish Detection data as JSON at PORT: 5557
                    - Shape detection
                    - Aruco tag detection   
                -   2nd Publisher : streaming video with detected overlay at PORT: 5558

            - Nav/run.py
                -   script that solving the maze using data from both Camere Node and Robot Node.
                -   algorithm as discribed in presentation.

*** To run the Robot ***
    ** These 2 nodes need to be running.
        - Driver/robot_service.py 
        - Vision/camera_server_vid.py

    Nav/run.py - to exploration the maze and get back to starting point.

*** SIMULATION ***
bypassing robot low-level and camera. instead of finding junction as new node.
it will retrun node found in that exploration.
No Service require to run. (mimic robot_service and camera_server_vid in demo script.)

each time maze will be generate randomly
    - size is configable in `Nav/lib/maze_generator` at the bottom line.

```bash
cd Rpi/Nav
python demo_run.py
```
*** REAL ROBOT RUNNING ***
Start 2 service and run exploring script.py should enough to run the robot.

1. Start Hardware Driver & Service (on Raspberry Pi)

```bash
cd Rpi/Driver
python robot_service.py
```

2. Start Vision Server (on Raspberry Pi with camera)

```bash
cd Rpi/Vision
python camera_server_vid.py
```

3. Optional: View Live Camera Feed

```bash
cd Rpi/Vision
python camera_viewer.py
```

4. Start Autonomous Exploration (on local machine or Pi)

```bash
cd Rpi/Nav
python run.py
```
